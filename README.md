# Sevas-Ping · Telemt

Русскоязычное меню для установки и обслуживания Telegram-прокси Telemt на Linux.

## Установка

Нужны Linux с systemd, Bash, curl, Python 3.11+ и права администратора. Подходят Debian 12 и Ubuntu 24.04. Скрипт проверяет контрольную сумму установщика Telemt и устанавливает Telemt 3.5.17 как системную службу.

```bash
installer="$(mktemp)" &&
  curl -fsSL --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/egMRL/sevas-telemt-installer/dfe1702eda31563d1083e12fef86168d1687cd63/menu.sh' -o "$installer" &&
  sudo bash "$installer" setup
```

Если вы вошли как `root`, выполните последний шаг без `sudo`. Для повторного вызова введите `menu`. Если имя уже занято, используйте `sevas-telemt-menu`.

Если Telemt уже установлен, команда обновит меню. Выберите **2. Проверить статус**. На новом сервере для установки Telemt выберите **1. Установить или обновить**.

При установке меню показывает текущий этап и выводит сетевые ошибки. На каждую попытку скачивания архива отводится до 60 секунд.

## Управление прокси

Через меню можно установить или обновить Telemt, посмотреть статус и журнал, перезапустить службу, получить ссылку Telegram и настроить канал-спонсор. При удалении Telemt конфигурация сохраняется. Изменения тега и обновления сохраняют резервную копию в `/var/backups/sevas-telemt`.

При установке выберите свободный порт TCP и убедитесь, что он открыт во внешнем файрволе хостинга.

## Канал-спонсор

1. В разделе «Канал-спонсор» откройте параметры регистрации. Скопируйте публичный адрес с портом и исходный ключ из 32 шестнадцатеричных символов.
2. В [@MTProxybot](https://t.me/MTProxybot) вызовите `/newproxy`, отправьте адрес с портом и исходный ключ. Бот выдаст тег.
3. В меню добавьте тег от бота. Скрипт задаст `ad_tag` и включит `use_middle_proxy`.
4. В @MTProxybot откройте `/myproxies` → **Set promotion** и укажите публичный канал.

Для подключения пользователей используйте ссылку из меню Telemt с секретом формата `ee`. Смена общего тега сохраняет ссылку при прежнем адресе, порте, TLS-домене и ключе.

Канал отображается в поддерживаемом клиенте Telegram. По документации Telemt обновление может занять около часа. Проверьте с аккаунта, который ещё не подписан на канал. [FAQ Telemt](https://github.com/telemt/telemt/blob/main/docs/FAQ.ru.md#как-настроить-канал-спонсор-прокси-и-статистику-через-бота-mtproxybot)
